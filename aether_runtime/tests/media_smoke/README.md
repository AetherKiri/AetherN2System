Run `sh aether_runtime/tests/media_smoke/run.sh /path/to/libaether_n2system_media.dylib` from the package root. The script generates synthetic WAV, Vorbis, MP3, and MPEG-4 video fixtures in the temporary directory, compares the generated C# layouts against native FFmpeg 8.1 headers, decodes through custom managed Stream IO, checks PCM output, seeks after EOF, and exercises MediaStream through a capturing audio source. It needs a C compiler, the .NET SDK, and an FFmpeg command with the native Vorbis, libmp3lame, and MPEG-4 encoders. `FFMPEG_BIN`, `FFMPEG_INCLUDE_DIR`, and `CC` override tool and header paths. No game assets are used.

To repeat the checks under NativeAOT, first run the script to create the fixtures, publish with `dotnet publish aether_runtime/tests/media_smoke/MediaSmoke.csproj -r osx-arm64 --self-contained true -p:PublishAot=true -o /tmp/aether-n2system-media-aot`, then run `/tmp/aether-n2system-media-aot/NitroSharp.Tests /path/to/libaether_n2system_media.dylib "$TMPDIR/aether-n2system-media-smoke/ffmpeg-layout.txt" "$TMPDIR/aether-n2system-media-smoke/fixture.wav" "$TMPDIR/aether-n2system-media-smoke/fixture.ogg" "$TMPDIR/aether-n2system-media-smoke/fixture.mp3" "$TMPDIR/aether-n2system-media-smoke/fixture.avi"`. Change the RID, shim filename, and temporary path for the target platform.
