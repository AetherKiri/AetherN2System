The Aether host builds the existing NitroSharp engine as an in-process NativeAOT shared library. Its C contract is in `include/aether_n2system.h`. A host owns the event loop and receives borrowed, top-down RGBA8 frames; the engine uses an offscreen Metal, D3D11 or Vulkan framebuffer and creates no SDL window. Calls for each instance must run serially on its creating thread. Distinct instances may use separate threads. `destroy` releases the instance and another game can then be opened in the same process.

Build with `./aether_runtime/build_host.sh` or `dotnet publish aether_runtime/AetherN2System.Host.csproj -c Release -r osx-arm64 -p:NativeRid=osx-arm64 -o OUTPUT`, replacing the RID with the native desktop platform. A .NET 10 or newer SDK with NativeAOT support and the platform C toolchain are required. Cross-OS NativeAOT publishing is not supported. Generated shader resources are checked in; regenerating them after shader changes requires `glslangValidator`, `spirv-cross`, and `python3 aether_runtime/compile_shaders.py`.

Deploy the complete publish output, including Fonts, beside the provider's N2 host library. FreeType must be provided for the target architecture with its dependent libraries. Aether's main CMake build supplies this dependency from vcpkg. The optional `stage_macos.py OUTPUT` script stages local Homebrew libraries for development tests; its output is not a release package and can require a newer macOS than Aether's deployment target. Native dependencies and Fonts are resolved relative to the shared library itself, independently of the process working directory. OpenAL output is implemented; macOS can use the system OpenAL framework. The inherited FFmpeg bindings expect the FFmpeg 4 library ABI, so media decoding requires matching native libraries; decoding commercial-game audio or movies has not been validated by the host smoke test.

Place an `aether-n2system.json` or `profiles.json` in the game directory using NitroSharp's existing profile format. Relative `dev.contentRoot` values resolve from that directory. A profile may omit optional display, icon and font settings. Without one, the host tries `nss/boot.nss` at 1280×720. Plain, uncompressed `nss.npa` scripts are extracted into the supplied writable directory, with path traversal and extraction-size checks; other NPA files are mounted under their file stem. Encrypted or compressed NPA archives return an explicit error. The game directory and process working directory are not modified. This bridge does not establish compatibility with any commercial title.

`python3 aether_runtime/smoke.py OUTPUT/aether_n2system.dylib` exercises the real native ABI using `manual_tests`, an input-driven color fixture, a generated plain NPA, repeated destruction and reopening, pause/resume, and compressed-archive diagnostics. `dotnet run --project aether_runtime/tests/AudioSmoke.csproj -c Release -- /absolute/path/to/libopenal.dylib` feeds generated PCM to the real OpenAL device and checks playback position and pause/resume. These checks do not validate commercial media decoding. Passing the FreeType library path and a font path as two additional arguments also rasterizes a real glyph. TextBlock itself remains incomplete in the inherited rebuild engine, so this does not establish working in-game text. The standalone `src/Game` entry point is preserved. The NativeAOT library stays loaded for the process lifetime; only game instances are destroyed.
